# Luminality : App MVP

## Key concept
An app where you can write positive things daily to improve your mental health

## Key features
1. Write something good daily
2. Calender view, timeline
3. Card view to look back
4. Mood tracking (optional)
5. Notifications to take note everyday
6. Quote of the Day (optional)

## UI Theme
* Warm theme
* Notebook look and feel
* Minimalistic
* Easy to read

## Monetization (Future plans)
* Upload to cloud storage
* Alternative themes
